# Brag Plan: Build2Buzz (GitHub LinkedIn AI Publisher)

## What is this app?
Build2Buzz is a local-first Windows application that analyzes GitHub repositories and working demos, extracts verified factual evidence, and drafts high-impact LinkedIn posts with mandatory human sign-off before publishing via official LinkedIn REST APIs.

## The angle
Developers build amazing software but struggle to craft authentic, technically accurate social posts without sounding like generic AI spam or leaking private API keys. Build2Buzz enforces an unshakeable evidence contract: every claim must be grounded in repo code or observed demo behavior, API keys never leave Windows Credential Manager, and nothing ever publishes without human approval.

## Hook (first 2-3 seconds)
A high-energy dark cinematic open with ambient neon cyan/indigo glow:
"Turn GitHub Repos Into High-Impact LinkedIn Posts"
"Without AI hallucinations or leaked secrets."

## Key moments (the middle)
- **Live Evidence Engine:** Real-time ingestion separating documented README facts from observed Playwright demo behavior with SSRF defense.
- **Human-in-the-Loop Post Editor:** Interactive post composer with live character count, proof tags, and strict approval enforcement.
- **Official LinkedIn Publishing:** One-click publishing to LinkedIn's official REST API with audit history and share URN confirmation.

## Outro / punchline
"Build. Showcase. Share. Your code deserves an audience that believes the facts."
Logo: Build2Buzz • Local-First & Windows Secure.

## User flow worth showing
1. Entry: Ingest GitHub repository (`github.com/gosaiyash/Build2Buzz`) & run Playwright demo inspection.
2. Evidence: Fact-checking engine categorizes verified technologies and flags unverified claims.
3. Review & Approval: Human edits the generated draft, checks char count, and clicks Approve.
4. Publication: Official LinkedIn API confirmation with permanent URN tracking.
